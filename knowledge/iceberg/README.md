# Apache Iceberg knowledge source

This folder contains the maintained, curated Apache Iceberg entries used by
the analyzer. Each topic is a top-level Markdown file and is seeded into the
knowledge index.

This README is source documentation only. It is deliberately excluded from
the knowledge index and deterministic retrieval so an inventory cannot be
mistaken for operational guidance.

The entries cite their authoritative Apache Iceberg source material. Add a
new reviewed topic as `knowledge/iceberg/<topic>.md`, then rebuild the index
with `python scripts/init_knowledge_db.py`.
