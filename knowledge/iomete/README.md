# IOMETE knowledge source

This folder contains maintained, curated IOMETE guidance used by the analyzer.
Each topic is a top-level Markdown file and is seeded into the knowledge index.

This README is source documentation only. It is deliberately excluded from
the knowledge index and deterministic retrieval so an inventory cannot be
mistaken for platform guidance.

Add a reviewed topic as `knowledge/iomete/<topic>.md`, then rebuild the index
with `python scripts/init_knowledge_db.py`.
